# Learnix

## Overview

Learnix is an educational platform for learning programming and technical skills through structured resources, course videos, and practice-focused workflows.

## Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: MySQL

## Project Structure

```text
learnix/
|-- frontend/
|   `-- public/           # Static pages, styles, scripts, media, uploads
|-- backend/
|   |-- src/              # Express server, routes, database config
|   `-- scripts/          # Backend utility scripts
|-- databases/
|   `-- sql/              # SQL schema and database assets
|-- .env
|-- package.json
`-- README.md
```

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/learnix.git
```

2. Navigate to the project directory:

```bash
cd learnix
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

## Usage

After starting the server, open `http://localhost:3000` in your browser.
